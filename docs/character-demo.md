# 随机人物模型演示

开发时运行 `npm run dev`，打开 `/?view=character-demo`。新增演示复用人物公开生成接口、appearance/3 原素材和现有动作工坊，没有另建人物接口或替换素材。

- 首次打开生成随机姓名、年龄、职业、背景、性格、偏好和匹配的外观。
- 点击“随机下一位旅人”，或下方“随机新外观”，生成完整新人物；旧预览会清理动画帧和键盘监听。
- 输入同一种子或保存生成后的地址，可以复现初始人物；地址不记录后续手动改装和动作状态。
- 八向按钮或 WASD / 方向键预览移动；动作、武器、法术、表情和外观沿用动作工坊控制。
- 原始人物数据、动作接口及既有外观工坊保持兼容。动作页可以接受指定 appearance/gender，供演示直接传递同一人物。

独立托管可以在 HTML 添加 `<meta name="hi-story-default-view" content="character-demo">`，让首页直接进入演示。仓库原首页继续保留故事入口。

本次验证：128 项单元测试、TypeScript 类型检查、模块边界检查和生产构建通过。环境没有提供 Sites 要求的 control-browser 能力，因此本轮未新增浏览器交互验收。原方向遮挡修复的浏览器与像素证据保存在 `docs/evidence/character-directional-v3/`。

目前为分层骨骼原型；大幅动作、侧背面细节和不同部件的风格一致性仍需继续精修。
