# 战斗魔法与技能选择：候选验收

2026-10-18，Windows / Node 24.16.0 / 本机 Chrome。分支 `codex/combat-skill-choices`，基于已推送装备候选 `28a8d47`。本轮交付源码与本地生产构建，线上仍为 v0.5.0。

## 实际功能与操作

进入主冒险→旅程→职业规则，选择职业并生成新旅程。战斗点击“魔法/技能”，选择能力，查看效果、射程、资源消耗与合法目标，再确认使用。选择期间隐藏基础行动区，可用“返回基础行动”取消；地图点击人物只选择技能目标，默认不预选目标；点击战场或下拉选择后才启用确认。点击/键盘选择不结算。375px 面板可以滚动和收起。

- 新增18项一级能力：法师/术士各四系单体法术；五种装备武器战技；武僧凝气掌；牧师/德鲁伊/吟游诗人/游侠的基础治疗。当前总目录270项、实际主动执行27项；另外243项仍不能施放。
- 火/冰/风走技能攻击命中，雷走敏捷豁免；自然1必失、20重击，豁免成功无伤害。合法使用消耗所属职业1资源与一次主行动，未命中或豁免成功仍扣费。
- 装备战技实际读取武器命中、伤害骰/加值和射程，再叠加技能骰；一次技能只攻击一次。重击翻倍两部分骰子，属性只加一次。法术不读取武器伤害。
- 治疗限存活且受伤的合法人物；战斗中不能治疗敌人，攻击不能选自己或非参战者。无行动、资源不足、射程外、障碍视线和满生命会显示原因，确认按钮禁用；实际命令仍由运行器复验。
- 查询与选择不修改生命、行动、资源或RNG。已提交结果通过原骰子反馈播放，失败回滚、重复命令与战利品仍走原事务；刷新恢复相同资源、行动和随机流。

原职业存档直接恢复并查询新能力，不补充资源；四模板角色保持原规则，界面提供新职业旅程入口。产品/快照0.6.0、schema5/demo-contract/5、class-framework/1、save1及保存槽保持。`profession-combat-options/1` 是新增只读选择契约，无新增持久状态。

## 开发期失败与修正

首轮逻辑失败来自新增目录计数仍按252/9断言、测试快照包含JSON不会保存的undefined，以及受控战斗漏填obstacles；已纠正测试数据，最终完整384项通过。技能越界错误文案保留“范围”语义，原规则回归通过。

第一批浏览器22项中20项通过，两个尺寸的技能刷新用例失败：受控导入的种子是 `battle-picker-fixture`，测试URL却指定 `picker-import`；刷新按既有启动规则重新开了另一种子，因而没有战斗按钮。修正测试URL与导入种子一致，保留原启动规则。首批完整报告和失败trace在Git忽略的 `_handoff/audit/combat-skills-browser-20261018.json` 与 `_handoff/audit/combat-skills-first-browser/`；14项装备/HD-2D回归为首批明确通过的子集，不将首批描述成一次全绿。

最终技能面板另压缩基础行动占位后重新构建复验；暂停测试时钟的截图等待实际场景和战斗人物加载，不以占位图宣称画面完整。
