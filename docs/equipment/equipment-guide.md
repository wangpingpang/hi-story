# hi-story 职业之书 · 装备与外观 v1

12职业、36专精、102件装备设计，玩家、伙伴、敌人与居民共用。以DND职业概念为灵感，以下为hi-story原创装备原型，不是官方DND数值。

## 当前实现

装备定义与静态外观原型；8方向逐帧素材与游戏背包穿戴界面待接入。

定义、所有权引用、槽位/熟练/双手校验、战斗数值候选、体型布局、正面静态装配与网页试穿已实现。运行器战斗仍采用原职业训练值；尚未接通游戏中的装备获取、穿戴命令、背包实例、保存与装备结算。网页试穿使用独立虚拟衣橱，不写入游戏。

## 统一穿戴规则

九槽位：衣甲、主手、副手、头部、足部、项链、左戒、右戒、腰饰。定义ID对应样式，instanceId对应实际物品；同一实例至多在一个槽位。不同实例可引用相同样式。

双手主手与副手互斥；切换前先卸下冲突副手。护甲训练与武器熟练根据职业/专精字段校验，推荐仅表示适合，不代表为角色凭空发放物品。常规帽靴、饰品不提供额外AC。副手匕首不自动增加攻击次数或AC。

| 甲类 | AC候选 | 适配说明 |
| --- | --- | --- |
| 无甲 | 10＋敏捷，或已解锁职业公式取最大 | 武僧公式不可持盾；野蛮人公式可持盾；龙裔公式不可持盾 |
| 轻甲 | 11＋敏捷 | 软皮、便于潜行与移动 |
| 中甲 | 13＋min(2,敏捷) | 锁片与软甲结合，负敏捷照实计算 |
| 重甲 | 16 | 板甲，要求重甲熟练 |
| 盾 | 选定基础AC后＋2 | 不与双手武器共用双手 |

基础装备仅提供上述候选数值与武器伤害骰/距离；稀有度、重量与价格尚未平衡，不据此发放魔法属性。法器/乐器的武器家族是动作接口的持握降级分类，不表示乐器可按长杖完成所有武技。法术的伤害与命中仍由技能执行器决定。

通过训练、经验与纪律掌握武器的冒险者。战士擅长在狭窄地形保护同伴，也能研究敌人阵型、组织守夜和指导民兵。勇气、残忍或仁慈由个人经历决定。
