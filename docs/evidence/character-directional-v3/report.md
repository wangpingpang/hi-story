# 人物生成器 2：方向饰品遮挡

基线：`codex/character-profiles` 的 `ddcd463`。本轮使用原素材，渲染版本升级为 `character-motion-art/3`；人物数据接口、外观样式 ID 与种子算法保持不变。

## 修复

- 披风从正面和侧面观察时绘制在身体后方，留出侧边和下摆轮廓；从斜后和背面观察时覆盖躯干。动作中继续绑定同一身体变换。
- 吊坠不再绘制在 NE、N、NW 的后背上。
- 眼镜不再绘制在 NE、N、NW 的后脑上。

## 验证

类型检查、模块边界、构建、128 项单元测试和 28 项桌面/窄屏浏览器测试通过；最终披风尺寸调整后又通过 10 项动作浏览器测试。

最终全量贴合采样 5120 帧，独立大块断缝候选、动作边缘截断、192 个静态导出边缘截断均为 0。该指标仅用于发现缺陷候选，不等同于美术质量评分。

饰品回归共 260 项：男女、八方向、站立/行走/招手/施法、两个动作相位；逐像素比较吊坠/眼镜与无饰品帧，验证前向可见、背向隐藏。披风还检查正面上衣内部不被覆盖，背面上衣被覆盖，并要求至少 50 个像素变化，避免完全隐藏披风仍判为成功。

人工查看 `accessories.png` 和 `attachment-motion.png`，后者包含三种饰品、四种动作、八方向共 96 个单元。详细结果见同目录 JSON。

仍为分层骨骼原型，尚有素材风格、侧背面细节和大幅转动时分段痕迹需要后续精修。本轮并未声称全部搭配达到最终美术质量。
