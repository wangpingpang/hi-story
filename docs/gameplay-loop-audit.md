## 复现与修正

| 问题 | 原先的断点 | 本轮结果 |
| --- | --- | --- |
| 支线不可逆选择 | 保留草药/绕行后，事件已结算，交付/修路委托却一直进行中；晚接也会挂起 | 已接委托进入失败并说明选择原因；未接委托保留禁用原因，命令同源复验；医者离场关闭交付 |
| 失败检定 | 治疗草药/搬木失败后，原事件不可再选，没有推进任务的入口 | 原地点出现一次补救，交一份银叶草或消耗攀登绳；仍走原任务奖励账本，重复/恢复不多扣不多领 |
| 终局任务 | 主线成功结束整局，其他支线仍显示进行中 | 未完成支线关闭并注明旅程结束；旧档做同样的无奖励收尾 |
| 截止时间 | 39.9小时交付，耗时后40.15，结局失败但主线显示成功 | 显示完整交付耗时不足并拒绝；恰好40小时可完成；超时失败和旧矛盾终局统一为主线失败 |
| 行动提示 | 缺材料/金币时，附近的选项整条隐藏 | 按真实互动范围列出，禁用行动保留可读原因；补货后可返回完成 |
| 人物列表 | 点击可见人物只打开远处的不可用对话 | 使用已有寻路先实际靠近，再打开交涉，不能远程执行 |
| 普通法术显示 | 法师等显示d8+3，实际法术是d8；牧师圣焰被显示成命中攻击 | 新只读投影与执行共用技能选择，显示真实骰数、加值、命中或豁免DC；装备预览同步，旧装备保存字段不变 |
| 敌人绕路 | 射程内视线受阻站桩；短路线修复遇长墙又往返 | 从回合起点检查原接近路线，必要时寻找可攻击站位；按原3/4格预算执行实际路线，不穿墙或活体，无路不伪命中 |

三条主线以及承诺/回声等既有成功链原本可以完成；缺陷主要在失败、错序和终局边界。基础攻击按钮隔墙时仍可能可点击，最终由运行器拒绝并提示；技能选择器已有视线原因，此项未扩展为本轮新接口。

## 数据与兼容边界

- `AdventureApplication.queryQuestOptions()` 提供 `adventure-quest-options/1`；`quest.accept` 使用同一判定，不允许直接接取尚未触发的连续链。
- `AdventureApplication.queryBasicAttack()` 与装备投影提供 `basic-attack/1`；`EquipmentCombatProfile` 的存档值保持，避免破坏已穿戴旧档校验。
- `BoundAdventureChoice.inRange` 来源于运行器 `canInteract`，只读、不写存档。表现层仍不能结算规则。
- `closeAdventureTasks` 只关闭活动任务，不奖励。恢复先验证原始快照，再补已提交失败事实对应的入口和任务状态，复验后保存；不重抽骰子、不重扣资源、不重发历史奖励。
- 旧“主线失败但任务成功”修正只针对无奖励的主线蓝图，既有支线奖励不撤销。真实结束后未完成的支线用现有 `abandoned` 状态表示，具体原因说明自动收尾。
- 怪物视觉、施法/跑步、左右阵营、手动关闭骰子、原素材阴影和1.5倍默认缩放沿用。

## 验证记录

初始基线：408项逻辑通过；桌面真实三主线、承诺与六支线链、主线失败补救共5项通过。第6项旧战斗胜/败/逃跑用例超时：测试冻结了浏览器时钟，却未推进后来加入的跑步动画，等待被禁用的“结束回合”。补上推进动画并手动关闭骰子的测试辅助后，两种尺寸三结果均通过；没有绕过实际结算。原失败报告保留于 `evidence/closure-baseline-desktop.json`。

新增逻辑覆盖任务分叉/错序、补救、期限、旧档收尾、真实攻击、资源耗尽与短长休、遮挡和长墙绕路。新增界面覆盖靠近、材料补货、委托终态、真实法术属性、失败补救和截止时间，并核对桌面1440×1000和375×812。最终全量逻辑426/426通过（32个测试文件），详见 `evidence/gameplay-closure-logic.json`。

首轮新界面及修正后的战斗结果10项通过，记录 `evidence/gameplay-closure-browser-first.json`。随后增加期限/补救浏览器用例，调整禁用原因的可读性，并让截图等待场景实际绘制；这些变化的最终结果另记，不覆盖首次报告。

测试开发中保留以下实际修正：任务测试曾使用重复探测骰子编号、含undefined的序列化夹具和空导航路径，修正后通过；材料提示断言从“绳索”纠正为实际目录名“攀登绳”；长墙用例在短路线补丁下先失败，再修正回合起点规划后通过。这些夹具/代码失败不计入最终通过数量。

## 后续验收方式
