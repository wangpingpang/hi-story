# 地图生成器 v1 验证记录

以下是aac1b14地图独立开发时的历史验证；其94项总数与“尚未接入”描述不代表当前集成分支。2026-10-14地图已通过故事空间适配接入新Demo，本轮145项全项目验证见[集成报告](demo-integration-report.md)。生成API没有变化，浏览器视觉检查仍待完成。

## 完成内容

- 单人、有界、二维格子地图，宽高各最多 256 格。
- 完整故事参数驱动：区域、连接、地貌、关键点及对象位置。
- 种子复现、固定位置、矩形及椭圆栅格化、四方向路径查询。
- 空间与引用验证、对象间距/重叠规则、必达路线保护。
- 布局策略注册与注销，结构化失败反馈，有限重试。
- 命令行调用、完整 JSON 结果及 SVG 空间校验图。
- 根目录《地图生成器说明.md》与 AGENTS.md 调用约定。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| `npm run typecheck` | 通过 |
| `npm test` | 5 个测试文件、94 项测试全部通过 |
| 地图专用测试 | 19 项通过，其中多种子测试实际生成并检查 120 张地图 |
| `npm run check:boundaries` | 通过，领域/公开接口/表现层/浏览器边界符合约定 |
| `npm run build` | 通过 |
| `npm run maps:generate -- --output docs/examples/generated-map-v1.json --svg docs/examples/generated-map-v1.svg` | 成功返回，退出码 0 |
| SVG 文件结构 | XML 解析通过 |

示例输入固定为 40×28 格，3 个区域、2 条连接、3 个关键点、1 个地貌实例、2 个对象。实际输出可通行格子为 356；出生点至任务点四方向可达。守卫最终位置为 `(12, 6)`，符合距村庄大门 1—3 格的要求。

封闭通道、不可能放入的对象、会截断必达路线的墙体、错误引用、错误大小、未知策略及故障策略均有相应失败验证。失败不修改故事原始输入，也不发布半成品地图。
