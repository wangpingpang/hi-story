# 随机故事生成器 v0.2

入口：`/?view=story-generator`。不调用 AI API，运行时不联网。

## 已实现

- 有种子的本地随机组合：4类冲突、4区域、5背景、8姓名、6身份、6个性；每局3个 NPC，生成后保持身份不变。
- 每局1条主线、1条支线。初始18个选项；行动按对象和世界条件生成，随条件失效撤销。
- NPC保存身份、个性、地点、目标、事件、回应、线索、存活与信任；世界时间和日志提供事件时间。
- 初始化、玩家行动、外部世界变更三个公开入口。行动含版本检查，结果编号去重；处理过程使用工作副本，非法输入不污染原状态。
- 变化后重检全部任务和行动条件，小规模世界采用全量重检，尚未做依赖索引优化。任务声明依赖字段便于后续扩展；反应规则可有限级联，每个对象每个事务只执行一次。
- 死亡终止原委托和互动，其他知情者与既存笔记提供有依据的替代路径；全部线索丢失进入失败终局。
- 支线成功、失败、放弃、过期；主线成功、失败、主动退出。已终止任务保留结果，后续资源损失不会改写过去完成事实。
- 地图输出结构化 region/tags/npcIds 需求；战斗返回请求，由外部模块报告死亡或耗时。页面提供明确标注的战斗结果模拟按钮。
- 类型、应用与展示分离，原雾桥剧情和人物工坊保留。
- 行动与任务结算规则已迁移为 JSON 包，支持运行时注册、替换和卸载扩展；详见[规则包契约](story-rule-packs.md)。

## 接口

`initializeStory(seed, background?)` 返回世界。背景含展示文本与标签。

`storyOptions(world)` 按实时条件返回行动。

`processPlayerAction(world, { id, revision, optionId })` 返回新世界或待结算战斗请求。

`receiveWorldChange(world, resultId, change)` 接受人物死亡、时间、地点通行、物资、笔记变化，返回新世界。外部集成负责验证结果真实性、关联战斗请求并处理网络权限。

## 本版边界

这是可运行的规则原型。四类冲突有明确结局，但尚未实现多阶段任务图规划、完整事件链规划、独立NPC计划、认知/事实隔离、历史加权抽样、复杂技能骰检定、多人或存档导入校验。背景文字和标签目前保存展示，尚未影响规则选择；个性用于描述，信任用于反馈，尚未影响所有行动概率。地图仍由未来地图模块实现。

任一**受支持状态**变化都会重检；NPC迁移、关系网、物品所有权等需要后续增加对应变更契约和规则。禁止外部直接修改内部对象，应通过上述入口提交变化。

下一阶段可扩充素材与条件规则，再将当前全量重检替换为依赖索引队列；不能将声明的 dependencies 字段误认为已经实现通用依赖图传播。

## 验证

原9项故事逻辑测试包括100种子路径检查、死亡、线索消失、到期、幂等、通行变化、拒绝与完成、版本失效、战斗边界。新增15项规则包逻辑测试，合计全项目90项逻辑测试通过。浏览器覆盖桌面与手机入口、18选项、死亡联动、完成路径及规则装卸；详见规则包设计文档。
