## 新增风险验证

- 取得线索、购买物资、抵达、完成任务的真实闭环。
- 金币与物资变化、任务状态变化记录在同一次事件结算中。
- 成功命令重试返回原回执；同编号不同载荷拒绝。
- 换编号重放已结算事件、规则包替换或重新安装均不能重复领奖。
- 一次性事件的两个选择共用实例；可重复行动使用新的发生实例。
- 物品数量不足、中途执行错误、提交故障、规则包提交故障、重开失败均保留旧状态。
- 执行失败不消耗随机状态，不留下资源、任务、事件或命令回执的部分变化。
- 旧局命令拒绝；同种子重开后发起相同战斗，旧请求结果仍不能误结算新请求。
- NPC 死亡/离开使交互失效；返回后保持未结算事件身份。
- 通用 item/clue 字段连锁反应继续更新任务阶段。
- 返回快照独立且深冻结，不能污染权威状态。
- 非法数量、溢出、危险物品 ID、重复线索和任务终局重新打开均拒绝。

## 浏览器闭环

在故事工坊加载“行囊探索”，打开行囊获得绳索和线索，卸载再加载后无法重复打开或卖出，消耗绳索换取任务物资，然后抵达并完成目标。新局重置背包和结算记录，行囊重新出现。桌面与 375 像素窄屏均通过，未检测到水平溢出或页面错误。

## 复验命令

```bash
npm ci
npm run typecheck
npm test
npm run check:boundaries
npm run build
CHROMIUM_PATH=/path/to/chromium npm run test:e2e -- --grep '故事|阶段|探索事件|战斗等待' --reporter=list
```

缺少 `/usr/bin/chromium` 时应设置 CHROMIUM_PATH。本轮标准 Playwright 浏览器下载返回无效压缩包，使用临时安装的 Chromium 运行验收；临时浏览器包未写入项目依赖。

当前限制：故事地点内的选择探索、单人内存局、模拟战斗结果；独立地图生成、格子移动、持久存档和完整战斗尚未接入。
