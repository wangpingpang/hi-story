# v0.4.0 自测与迭代记录

基础99f1bc8；分支codex/v040-world-polish。代码和实际体验检查已通过，线上发布引用在发布后补充。

## 发现与修复

1. 对照实际桌面/375px截图，原版出现人物被营火和路牌遮住、建筑下方水洞、暗色网格边界与空白区域。重构连续地表、地区地基、暴露高差、密林和村路，缩小/错开出生道具。
2. 初版丰富景物后，每帧对整幅大地图模糊开销过大。改成四分之一分辨率迷雾缓存，仅视野变化时生成模糊；静止场景最多30fps，减少动态效果最多约7fps。
3. 自动靠近初版把寻路返回的空数组当作已经抵达。改为只接受可达候选或当前所在点，不能到达时明确提示；所有移动仍提交原world.walk。
4. 新测试最初直接使用actors.player，但运行器通过playerActorId绑定角色；修正测试读取动态身份，保留首轮失败记录。
5. 本地单进程Chromium无法连续创建测试上下文，造成衣橱用例在newPage阶段失败；改用常规多进程Chromium153，未将此问题误算为游戏失败或通过。
6. 进入战斗时保留探索场景，以固定局部原点显示战术区域；移动范围由应用门面委托运行器计算，避免表现层自行推测可达格。
