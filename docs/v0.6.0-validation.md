## 实际功能

- 商道营地实际靠近医者后购买：4 种武器、3 种护甲和圆盾，态度影响价格；林间补给成功整理/控制物资发放匕首。
- 装备是唯一实物，穿戴/卸下改变同一引用。显示九槽、已拥有物、图标、熟练、限制与属性预览；失败不扣金币、不改物品/随机状态。
- 命中、伤害骰/加值、目标防御与射程参与真实结算，普通与职业模式均接入；战斗中保持当前配装，卸下恢复原基线。
- schema5 / demo-contract/5 / snapshot0.6.0；save1 封套与 world-v2 保存槽保持。真实线上 v0.5.0 schema4 样本先核验再补空装备升级，runtime/story/原 things 字段及 RNG 保留；原恢复行为仍更新 runId、清空会话回执。装备来源账本保留幂等。
- 375px 战斗面板可收起，实际露出近战移动格，再展开操作；该状态仅属于表现层。

人物继续使用现有 28 人完整动画，穿戴暂不改变造型。首批不包含 NPC 装备、出售/丢弃、完整八向换装和 schema3 地图迁移；没有将这些后续项目标为完成。

## 实际修复与重跑

本轮并非第一次全绿：初期新逻辑测试的封套助手保留了 `undefined`，与真实 JSON 保存不一致；序列化后再算校验和。职业战士测试对一级敌人一击结束战斗，后续“结束回合”断言不适用；改为合法升级的耐久目标，继续检查真实攻击阈值。最终完整 362 项通过。

首批桌面装备流程走完战斗与导入，但刷新检查在暂停测试时钟后等待绘制，没有推进时钟；修正等待方式并保留原失败记录。第二批 8 项中 7 项通过，375px 近战移动实际被展开面板遮住；修复产品面板收起/展开后，34 项回归通过。没有用强制点击绕过遮挡。相关本地原始失败产物保留在 Git 忽略的 `_handoff/audit/v060-first-browser` 和 `v060-mobile-obstruction`。

最后流程命令最初使用 `npx.cmd --grep` 时，Windows 批处理把正则中的管道符当成命令分隔；当次未启动测试。改为直接调用 Node Playwright CLI，保留实际运行报告。未修改产品规则或放宽断言来掩盖这些问题。
